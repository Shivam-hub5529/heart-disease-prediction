# ❤️ Heart Disease Prediction App

A machine learning web application that predicts heart disease risk based on medical input features.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- FastAPI
- HTML
- CSS
- JavaScript
- Vercel

## Machine Learning

The application uses a Random Forest Classification model.

The model is trained using the following features:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise Induced Angina
- Oldpeak
- ST Slope
- Number of Major Vessels
- Thalassemia
